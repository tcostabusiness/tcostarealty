## Upload to GitHub
1. Unzip this folder.
2. Open the unzipped folder.
3. Upload the files inside it to the top level of your `tcostarealty` repository.
4. Confirm `index.html`, `styles.css`, `script.js`, and `assets` appear at the repository root.
5. In GitHub, go to Settings → Pages.
6. Choose Deploy from a branch.
7. Select `main` and `/(root)`.
8. Leave Custom Domain blank until the GitHub Pages URL works.
